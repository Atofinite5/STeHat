# WhisperMesh Releases

This directory contains verified binary releases and macOS `.dmg` installer bundles.

## Latest macOS Release

- **File:** `WhisperMesh_1.0.0_aarch64.dmg`
- **Architecture:** Apple Silicon (`aarch64` / M-series Macs)
- **Version:** `1.0.0`
- **Size:** `8.4 MiB`

### Features in this Release:
- **Direct WebRTC P2P DataChannels:** Sub-20ms latency laptop-to-laptop messaging.
- **Unique Machine Space Addresses:** Each laptop has its own permanent, hardware-derived space code.
- **macOS "Connect to Space" Window (`⌘K`):** Native modal with favorites list and OTP security code.
- **100% Local Encrypted Vault:** Zero cloud persistence; one-click Markdown/JSON transcript download.
- **Zero Cost & NAT Traversal:** Public Google/Cloudflare STUN servers for cross-network connectivity.

### How to Install:
1. Double-click `WhisperMesh_1.0.0_aarch64.dmg`.
2. Drag `WhisperMesh.app` to your `Applications` folder.
3. Open `WhisperMesh` from Applications.
